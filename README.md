# SkillPatch Academy Frontend

## Overview

SkillPatch Academy is a web interface developed to manage employees, training initiatives, and certification programs.

This frontend consumes data from the SkillPatch API and displays employee information in a modern dashboard interface inspired by Academy and Learning platforms.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

---

## Features

- Employee dashboard
- Employee counter
- Dynamic employee cards
- API integration with Flask backend
- Responsive interface
- Custom visual identity

## Installation

Clone the repository:

```bash
git clone https://github.com/ChristianoMiguelSamorideAzevedo/skillpatch-frontend.git
```

Navigate to the project folder:

```bash
cd skillpatch-frontend
```

---

## Running the Application

Open the project using Visual Studio Code.

Run the application using Live Server or open the `index.html` file directly in a browser.

---

## Backend Integration

The frontend consumes data from the SkillPatch API.

Default endpoint:

```text
http://127.0.0.1:5000/employees
```

Make sure the backend application is running before opening the frontend.
